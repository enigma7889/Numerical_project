# Triton Equations (SRG with Two- and Three-body Forces)

Implementation in python of Robert Roth’s project from https://chimera.roma1.infn.it/OMAR/ECTSTAR_DTP/roth/.
It consists in solving the quantum many-body problem for the ground state of the triton using an SRG-transformed chiral Hamiltonian (given in a predetermined basis) in the No-Core Shell Model
